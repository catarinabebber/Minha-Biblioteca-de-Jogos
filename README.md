# Minha Biblioteca de Jogos

## Sobre o projeto

Sistema para organização dos jogos que uma pessoa possui,
está jogando ou pretende jogar.

## Entidade principal

Jogo.

## Informações dos jogos

- Título
- Gênero
- Plataforma
- Ano de lançamento
- Status do jogo
- Horas jogadas
- Avaliação

## Tecnologias

- HTML5
- CSS3

## Etapa atual

Etapa 1 — Estrutura da interface utilizando HTML
e estilização com CSS.
